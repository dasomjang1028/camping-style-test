# 🏕️ 나의 캠핑 스타일은?

MBTI 기반 캠핑 성향 테스트 페이지입니다.

## 🎯 테스트 링크
👉 **[테스트 바로가기](https://[사용자명].github.io/camping-style-test/)**

## ✨ 특징
- 12개 질문으로 알아보는 캠핑 스타일
- 16가지 개성 있는 캠핑 타입
- 특별 할인 쿠폰 발급
- 결과 공유 기능

## 📊 수집되는 데이터
- 테스트 결과 및 답변
- 기본적인 방문자 정보
- 쿠폰 발급 내역

모든 데이터는 통계 목적으로만 사용되며, 개인정보는 수집하지 않습니다.

## 🏕️ 16가지 캠핑 스타일
- 완벽주의 리더 캠퍼 (ESTJ)
- 즉흥적 모험가 (ESTP)
- 따뜻한 케어테이커 (ESFJ)
- 자유로운 분위기 메이커 (ESFP)
- 전략적 캠핑 마스터 (ENTJ)
- 창의적 실험가 (ENTP)
- 영감을 주는 가이드 (ENFJ)
- 열정적 탐험가 (ENFP)
- 신중한 전통주의자 (ISTJ)
- 실용적 기술자 (ISTP)
- 조용한 수호자 (ISFJ)
- 감성적 예술가 (ISFP)
- 완벽주의 설계자 (INTJ)
- 분석적 탐구자 (INTP)
- 신비로운 몽상가 (INFJ)
- 이상주의 시인 (INFP)
